Try it yourself

The demo needs no GPU, no model and no API key. It red-teams a vulnerable toy app and the same app behind an output guard, and shows the CI gate failing the first and passing the second.

1. One click, on GitHub

Open the Try the demo workflow, press Run workflow, then open the finished run and read its Summary. (You need a free GitHub account.)

2. One command, on your machine

git clone {{REPO}}
cd llm-eval-redteam
pip install -e .
python examples/demo/run_demo.py

About a minute. Needs Python 3.10 or newer.

3. With a real model

ollama pull mistral
ollama pull qwen2.5:7b
llm-redteam ci configs/quickstart.yaml

About ten minutes on a laptop GPU; 6 attacks, undefended vs layered.

How far can the judge be trusted?

Agreement (Cohen's κ, with bootstrap 95% intervals) between each judge and 110 reference labels on the undefended responses. The headline figure is lifted by the deterministic detector; where an LLM has to reason, agreement is only moderate.

Read this before quoting numbers. The reference labels were written by an AI model, not by humans. The judge was revised twice after labels were seen, so every agreement figure is in-sample. One scenario, two 7B models, public unoptimised attacks, 20 to 25 cases per category. The paper lists the full threats to validity.
